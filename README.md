Synchro — локальный сервис для Windows. Он отдаёт видео телефону, принимает позицию просмотра обратно и связывает буфер обмена и ссылки между устройствами.

### На компьютере

- **Видео:** исходный файл по HTTP Range; продолжение просмотра и возврат на ту же серию.
- **Буфер:** последнее копирование в обе стороны. Передаваемый на ПК текст исключается из штатной истории и облачного буфера Windows.
- **Браузер:** отправка текущей ссылки через расширение или системный буфер.
- **Подключение:** локальный мастер с QR, установкой Android-приложения и сохранением настроек.
- **Обновления:** готовая сборка из GitHub Releases, с проверкой загрузки и сохранением пользовательских настроек.

### Быстрый старт

1. Распакуйте Windows ZIP целиком и запустите CMD-файл в его корне.
2. Подключите Android в открывшемся мастере. Оба устройства должны быть в одной сети.
3. Откройте видео в PotPlayer и продолжите просмотр на телефоне.

Python и ADB включены. Для автоматического фонового буфера Android нужен системный QR-сканер беспроводной отладки. Для видео и ручного обмена есть обычный QR приложения.

### Версии

**0.3.1:** один управляющий сервер, даже при запуске из разных папок или на разных портах.

**0.4.0 — в работе:** выбор источника (Windows Media Player, PotPlayer, VLC, mpv и YouTube), фотографии через буфер и новый интерфейс. Поддержка стандартного Медиаплеера Windows обязательна.

### Разработка

```sh
python -m pip install -e server
Synchro --open
python -m unittest discover -s tests
```

Python 3.11+, Windows 10/11. Плееры устанавливаются отдельно. `ffprobe` в PATH улучшает метаданные дорожек.
