# Синхро

Видео, последний скопированный текст и вкладки между Windows и Android в локальной сети.

- **Видео:** продолжить фильм/плейлист PotPlayer на телефоне; пауза возвращает файл, позицию, озвучку, субтитры и задержку на ПК. Передаётся исходный файл, без перекодирования. Громкость устройства остаётся локальной.
- **Буфер:** двустороннее автоматическое последнее копирование. Следующее заменяет предыдущее; приложение не ведёт историю. Передаваемый на ПК текст помечается для исключения из Win+V и облачного буфера.
- **Вкладки:** Opera → Поделиться → Синхро → свайп/кнопка → Chrome на ПК. Обратно — расширение Chrome и карточка на телефоне. Можно также скопировать адрес и открыть текущую ссылку из буфера в Opera.
- **Мини-плеер:** Home сворачивает видео в системный Picture-in-Picture с Play/Pause. Закрытие окна сохраняет позицию на ПК.
- **OTA:** стабильные теги GitHub Releases, SHA-256 загрузок; Android дополнительно проверяет пакет, версию и подпись APK. ПК сохраняет `.data` и откатывает программные файлы при неудачном запуске.

## Установка

[Windows ZIP](https://github.com/giveuper39/syncro-desktop/releases/latest) · [Android APK](https://github.com/giveuper39/syncro-android/releases/latest)

1. Распакуйте **всю** Windows-папку и запустите `Запустить Синхро.cmd`. Python и ADB включены.
2. Для автоматического буфера включите на Android параметры разработчика и **Беспроводную отладку → Сопряжение по QR-коду**. Сканируйте QR из мастера на ПК этим системным сканером.
3. В мастере нажмите **Установить и подключить**. Приложение установится, адрес/ключ сохранятся, автосинхронизация включится. IP, порты и коды вручную не нужны.
4. Если нужен только просмотр/ручной обмен, в мастере есть обычный QR приложения: беспроводная отладка не требуется.
5. Для видео откройте локальный файл в одном PotPlayer и нажмите **Продолжить видео с ПК** на телефоне.

Системное сопряжение предоставляет выбранному ПК ADB-доступ. Android ограничивает фоновое чтение буфера обычными приложениями; QR не обходит системное разрешение. После перезагрузки телефона может понадобиться включить беспроводную отладку снова. Синхро находит новый порт по mDNS для уже доверенного телефона. Root, замена клавиатуры и разрешение поверх других окон не нужны.

Для кнопки отправки вкладки в Chrome: распакуйте `chrome-extension.zip`, откройте `chrome://extensions`, включите режим разработчика и выберите **Загрузить распакованное расширение**. Оно запрашивает только активную вкладку и локальное хранилище, не читает историю браузера.

## Обновления и релизы

На телефоне: **Обновления Синхро → Скачать и установить**. Android один раз запросит разрешение установки из Синхро и подтверждение новой версии. На ПК: мастер `/setup` → **Обновления Windows**. Автоустановка работает в переносимой сборке, исходный checkout обновляется через Git.

Два независимых репозитория:

- [syncro-desktop](https://github.com/giveuper39/syncro-desktop): Python-сервис, Windows-пакет, ADB-мост и расширение Chrome.
- [syncro-android](https://github.com/giveuper39/syncro-android): нативное Android-приложение.

В каждом есть workflow сборки/публикации при `git push origin vMAJOR.MINOR.PATCH`. Версия исходников должна совпасть с тегом. У Android увеличивайте также `versionCode`; подпись хранится в GitHub Actions Secrets, приватный ключ не входит в Git. Сначала выпускайте Android, затем Windows: Windows включает последний стабильный APK. Подробности — [RELEASING.md](docs/RELEASING.md).

## Разработка

Сервис: Python 3.11+, `python -m pip install -e server`, затем `python -m potbridge --open`. Для dev-запуска также есть `start-server.cmd`. Для метаданных дорожек полезен `ffprobe` в PATH. PotPlayer устанавливается отдельно.

```text
python -m unittest discover -s tests -v
node --test chrome-extension/protocol.test.mjs
```

Android: JDK 21, Gradle 8.11.1, SDK 36 / build-tools 35.0.0. Из `android/`: `gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`. На Windows `android/build-local.ps1 -JavaHome <JDK>` скачивает проверенные SDK/Gradle в `.tools`. [Android README](https://github.com/giveuper39/syncro-android/tree/main/android).

Слои сервера: `player.py`/`win32.py` — PotPlayer; `sessions.py` — владение просмотром; `library.py` — ограниченный медиакаталог; `sharing.py` — текст/ссылки; `wireless.py` — QR/mDNS; `updates.py` — релизы; `http_server.py` — транспорт. Android отдельно держит представление, воспроизведение, PiP, обмен и обновление.

## Границы текущей версии

Поддерживается PotPlayer и локальные файлы/плейлисты. Другие плееры и YouTube — следующий этап. Автоматически переносится текст, не изображения/файлы. В Windows история существовавших до запуска копирований не очищается; сторонние менеджеры буфера могут применять собственную историю. При отключённой/недоступной отладке остаётся явная отправка текста из приложения.

Обмен идёт по доверенной LAN, видео/API используют ключ подключения. HTTP не шифрует локальную сеть; сервис не предназначен для публикации порта в интернет. QR/ключ не отправляются внешним сервисам. Тексты буфера не пишутся в логи и на диск. Ссылки во входящих хранятся в памяти до открытия/удаления.

LibVLC 3.7.7 содержит ограничение GNU_RELRO для некоторых 16 КБ устройств; полная совместимость с ними не заявлена.
