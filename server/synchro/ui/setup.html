Автоматический буфер

01
Откройте беспроводную отладку

На Android: Настройки → Для разработчиков → Беспроводная отладка.

02
Выберите сопряжение по QR-коду

Наведите системный сканер на код справа. Вводить IP, порты и коды не нужно.

03
Установите и подключите Synchro

Мастер сохранит подключение и включит автоматический буфер обмена.

Сопряжение даёт этому ПК ADB-доступ к телефону. Он нужен для фонового буфера. Root не требуется.

Для этого шага нужен системный сканер беспроводной отладки. Обычная камера используется в основном подключении.

Где найти параметры разработчика?

В разделе «Об устройстве» несколько раз нажмите номер сборки, затем вернитесь в настройки. На некоторых телефонах после перезагрузки нужно снова включить беспроводную отладку.
