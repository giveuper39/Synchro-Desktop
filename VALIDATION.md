# Проверка 0.3.0

- 69 Python unit/integration тестов: сессии, HTTP range/обрывы, авторизация, clipboard latest-only/no echo, ссылки, QR/mDNS, OTA digest/пути/версии.
- 14 Android JVM unit-тестов; debug/release сборки и lint без ошибок (предупреждения зависимостей/ресурсов остаются).
- 3 Node-теста протокола расширения Chrome.
- Нативный Android instrumentation: отправка конкретного текста и очистка поля, Opera→Chrome, входящая вкладка→браузер и удаление из inbox.
- Нативный PiP: Home продолжает видео, heartbeats не прекращаются, sharing Activity живёт под мини-плеером, системные Pause/Play работают, закрытие возвращает checkpoint на ПК.
- Прогон задержки: тёплый Play 23 мс в выделенном Android 14 эмуляторе на синтетическом видео; быстрый Pause и смена серии/позиции на тестовом ПК применяются корректно. Не гарантия задержки сети/устройства.
- ADB clipboard-мост действительно запущен на OnePlus с Android 16; передача последних копирований в обе стороны проверена Windows↔эмулятор, без чтения исходного личного буфера в логи.
- Python portable runtime 3.14.8: импорт сервиса, zeroconf, qrcode и Windows clipboard API прошёл без системной установки Python.
- APK: подпись, ABI, встроенная LGPL, ZIP и ELF PT_LOAD 16 КБ — проходят. GNU_RELRO остаётся ограничением LibVLC; полной 16 КБ совместимости не заявляем.

QR-формат/выбор mDNS-сервиса проверены тестами; реальный телефон ранее сопряжён по коду, поэтому полный сценарий первого сканирования системной камерой на новом устройстве требует полевого подтверждения. Обычный QR подключения был проверен на реальном телефоне.
