# QR-мастер

`/setup` и `/local/setup/*` доступны только с loopback и согласованными Host/Origin. Мастер использует штатный Android ADB QR: `WIFI:T:ADB;S:<random-service>;P:<one-use-password>;;`. Пароль живёт до 5 минут; сопряжение ищет строго mDNS-сервис из этого QR. После TLS-подключения пользователь нажимает «Установить и подключить»; мастер устанавливает APK, сохраняет app URI с адресом/ключом и включает мост буфера. Пароли сопряжения не сохраняются и не логируются.

Сканировать нужно **системным сканером из настроек беспроводной отладки**, а не камерой Synchro. Это системное разрешение на доступ ADB к телефону. Готовый телефон запоминается по серийному номеру; новый TLS-порт обнаруживается по mDNS. Не сканируются произвольные хосты/порты LAN.

Для видео и ручного обмена есть отдельный обычный QR `/pair`, без отладки. Он генерируется локально библиотекой qrcode и кодирует `potplayerreceiver://pair?v=1&server=<encoded>&token=<key>&name=<encoded>`. Старый URI и package ID сохранены для совместимости; также принимается `syncro://pair`. Ключ и адрес заменяются вместе, URI проверяется Android-парсером.

Страница загрузки и APK не содержат ключа. Для ссылки на том же телефоне ключ помещается только во фрагмент `/#pair=...` и не отправляется HTTP-серверу. Транспорт LAN остаётся HTTP: используйте доверенную сеть.
